# Student Manager

A simple Python application for managing student records.

## Features

- Add students
- View students
- Search students
- Unit tests
- Automated testing with GitHub Actions

## Technologies

- Python 3.12
- Git
- GitHub
- GitHub Actions

## Project Structure

```text
student-manager/
├── .github/
│   └── workflows/
│       └── tests.yml
├── .gitignore
├── README.md
├── student_manager.py
└── test_student_manager.py
Installation

Clone the repository:

git clone YOUR_REPOSITORY_URL

Go into the project:

cd student-manager
Run
python student_manager.py
Run Tests
python -m unittest
CI

GitHub Actions automatically runs the test suite whenever code is pushed or a Pull Request is created.
